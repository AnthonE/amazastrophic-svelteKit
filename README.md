# amazastrophic.com

The Amazastrophic company site: a single SvelteKit page that points to
[Elo Pros](https://elopros.com), our store for multiplayer games. Deployed on
Vercel.

## Developing

```bash
pnpm install
pnpm dev
```

## Building

```bash
pnpm build
pnpm preview
```

Needs Node 22. `pnpm check` type-checks, `pnpm lint` checks formatting, and
`pnpm test` runs the Playwright check against a preview build.
